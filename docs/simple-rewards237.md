# Simple rewards and future payments

Daily check-in uses a rolling seven-day reward grid with the existing game welcome artwork, diamond icons, completed marks and a highlighted current day. Rewards remain 20 + 5 per consecutive day, without a weekly reset. One claim button requests status if necessary and continues automatically to receipt creation and ad playback. Opening the treasury alone never launches an ad.

Resource Ads choices and reward hub buttons start their receipt/ad flow directly. Diamond purchase confirmation remains on a separate screen. Existing unverified expired requests are cancelled before replacement; verified or completed receipts are claimed rather than discarded. Changing reward types cancels an unviewed prior request before preparing the selected type. No client-only reward grants were introduced.

Future purchase direction requested by owner: Telegram-specific payment and fiat on Google Play. Current official Telegram rules require Stars (XTR) for digital goods, explicitly excluding cryptocurrency substitution, so direct TON-for-diamonds in the Mini App is not implemented. Google Play version should use Play Billing for diamond packs. No payment buttons or live charging are enabled in this patch.
