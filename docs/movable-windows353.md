# Desktop-style windows — content patch 126

Window menus have a full-width, sticky title grip. Drag immediately with mouse or touch; the 280 ms hold gate is removed. The menu heading and empty navigation-header space also drag the window. Buttons, links, fields, army cards and scrolling content retain their own actions. The title grip remains accessible when scrolling long menus.

The home menu, resource bar, commander panel, quick shops/calendar, zoom controls, battle commands and deployment toolbar can float or dock at the left, right, top or bottom edge. Release within 60 px of an edge to dock; a cyan target previews the edge. Horizontal edges arrange toolbar items in a row; vertical edges arrange them in a column. Dock placement tries free positions along the edge, then adjacent lanes to avoid other visible HUD panels. When the screen is saturated, viewport containment takes priority; users can scroll overflowing toolbars or move another panel. Moving the deployment toolbar releases the old reserved right-side canvas strip.

Building actions, placement confirmation/cancel, guide menus, login/name windows and the game's support/admin panel are movable windows. Native operating-system / Google Play payment windows are outside the game DOM and remain platform controlled. Normal modal dismissal, purchase confirmation, authentication and gameplay rules are unchanged.

Layouts persist per device in `novaWindowLayout353`, including edge, axis and normalized position. Patch 125 positions migrate. Rotate/resize clamps panels to the viewport; layout reset remains in Settings. Home and battle toolbars retain their proper screen visibility. Grips support arrow-key movement.

Verification: `CHROME_PATH=/path/to/chromium node tests/movable353-browser.cjs` uses the real bundled game and entry HTML with network mocked. Tests cover bottom placement controls, mouse/touch dragging, immediate touch on the heading, four-edge docking, horizontal/vertical rearrangement, two toolbars sharing an edge, HUD refresh during drag, normal action buttons, sticky heading on long content, all primary game menus, home/battle switching, portrait layout, resize/rotation, game reload persistence and reset. HQ engine/snapshot and platform isolation checks also pass. No physical Android-device test was performed.
