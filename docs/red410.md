## 412 save fix (patch 212)

Since patch 210 a save holds zdrill/ztank/inferno/skyguard buildings and 15 army slots, but `features/red410` registers those only after `var E=new Engine(localStorage)` runs. The Engine's save check rejected such saves and started a new base. game.js now registers placeholders (B types and U slots 11-14) right before the Engine is built; red410 replaces the U placeholders with `U.splice`. Regression: `tests/save412-browser.cjs`.
