# Shared sieges and alien mercenaries (content patch 9)

Up to four attackers join one defender battlefield (3 minutes from first entry). The first attacker simulates combat for everyone. The server serializes deployment commands, participants, shield checks, loot and results. The current host sends one shared frame every 1.5 seconds. A stale host lease expires after 10 seconds and another active participant, including the defender, can take over. This retains client simulation trust; it is not a cheat-resistant server combat simulator.

All players see the same building health and units. Each attacker can deploy at most 40 ordinary troops per battle, plus their automatically deployed mercenary half. Server deployment nonces prevent duplication. Unsaved/unprocessed commands and unused ordinary troops are returned. Ordinary deployed troops retain the existing consumed-on-deployment rule. Surviving mercenaries return; fallen mercenaries are removed.

Loot uses one pool: at most 60% of the defender's current crystal/gold/power balance, multiplied by destruction. Accepted deployments determine proportional shares (one unit is one share). Only actual accepted amounts within each attacker's storage are debited from the defender. Gems are never stolen. Finishing/retrying cannot settle twice. Both roles get signed resource amounts, mercenary losses, and a saved report. Server acknowledgments retain unseen reports across reconnects; the client keeps the latest 100 reports.

During defense, publishing a different layout and build/upgrade/train actions are blocked. Crystal, gold, power, alien production, construction and training timers pause. Local online progression only advances to server-confirmed time; server siege intervals shift timers across an offline period. Production resumes when the whole shared battle ends. A 30-minute protection shield then starts, so finishing one participant cannot interrupt the others.

The mercenary base reuses alien base sprite 13. Requires HQ 3, costs 1,000 gold + 500 power, builds in 60 seconds, and uses ordinary building upgrade rules. At level L it produces one alien every 120/L seconds up to 10+2L units (maximum 40). Half rounded down accompanies an attack automatically; the remainder protects the base. Guards intercept invaders anywhere in the base, flying past blocked paths. Alien HP increases with base level; the existing mech combat profile is reused. The existing alien fighter art distinguishes these units.

Validation: PGlite migrations and participant RPC tests cover shared sessions, idempotent deployments, access denial, loot conservation, persistent results, shield/freeze locks, odd splits, host failover and stale host rejection. VM/UI tests cover deploy queue, allied units, guard interception, maximum Android payload size, replay-safe return, reports and exact timer pause/resume. Legacy game/economy tests also pass. Physical multi-device latency/audio and visual QA still require device testing.
