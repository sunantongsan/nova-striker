# 393: Clash-style bot bases, random defense attackers, wall controls, window fixes

All code lives in `features/coc393/` and is appended by `features/titan342/build.cjs` after the window skin.

## Multiplayer bot bases (`bases393.js`)
`campaignLayout393(n)` replaces `campaignLayout299`. Each of the 100 stages is seeded by its number and picks an archetype (core box, offset core, compartments, ring, diamond, wheel, islands, layered rings, farming), then rotates/mirrors it. Walls are laid inner-first and trimmed to a budget that grows with the stage. A 0-1 BFS gives each cell its enclosure depth; buildings choose cells by role: HQ deepest (or outside on some farming bases), storages spread in the core, splash defenses near the core, point defenses spread outward, traps beside walls, army buildings and collectors outside. Counts follow HQ caps; levels approach the HQ tier on later stages. Stages 60+ use a 24×24 map. Defending squads (garrison) grow and mix unit kinds, and defender research rises every 10 stages.

## Defense waves (`defense393.js`)
Each wave rolls a plan (single side, pincer, surround, bursts, steady), an optional mutation (armor, frenzy, regeneration, heavy weapons) and a role mix unlocked by wave: runner 2+, brute 3+, sapper 4+, shield bearer 5+, healer 6+, a boss every 5th wave. Stats scale from the existing balanced enemy numbers. A toast announces the plan when the wave starts. Role cues are drawn over the alien sprite.

## Walls (`walls393.js`)
Tap a wall: [Info] [Select row] [Upgrade + cost] [Move]. After Select row: [Info] [Rotate row] [Upgrade ×N + total] [Other row at corners] [Cancel]. Upgrade opens a confirm window with before/after wall art, HP and price. Info lists walls by level and can select all walls or start drag-building.

## Windows (`windows393.js`, `coc393.css`)
The NOVA mech window uses two columns in landscape so actions fit, and skips re-rendering when a status refresh returns identical content (no preview flicker).
